# 历史人工调试资料

- root/：原根目录脚本及测试上传文件。
- scripts/：原 scripts/ 下的造数、登录与调试工具。
- browser/：原 public/ 的测试页面，已不由应用直接公开托管。

这些是归档资料，不是 CI 自动测试。部分脚本会删除数据、创建账户、输出令牌或包含固定演示密码；部分使用旧端口、node-fetch 的旧调用方式或过期接口。只可在审核内容后针对一次性隔离环境使用。不得将浏览器测试页重新放到线上 public，也不要执行历史脚本中的生产操作。

真实 Token 和用户快照已移除。需要人工调试时，自行在 root/ 创建被 Git 忽略的 test-token.txt、test-user.json，并使用短期本地凭据；不要上传这些文件。迁移后 scripts/ 的 .env 相对定位已指向项目根目录。其余历史说明保留原意，不承诺脚本仍可直接运行。

node --test tests/security/auth.test.cjs
